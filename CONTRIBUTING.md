# Contributing

1. Read `AGENTS.md` and `APP_SPEC.md` first.
2. Edit `src/index.template.html`, not generated files in `dist/`.
3. Keep the runtime dependency-free unless a new dependency materially improves reliability.
4. Preserve Japanese and English UI, mobile usability, keyboard access, and local-first behavior.
5. Run `build-standalone.bat` and the verification scripts before opening a pull request.
